# Калибровка дальнего распознавания (по пикапу Toyota Tundra)

**Дата:** 03.11.2026, 20:04–20:15 (уточнено субпиксельно по двум кадрам) · **Камера:** «Гостевой 13»
(`/cameras/12`, Line-сервер 192.168.1.250), поток `main` 1920×1080, ИК-ночь
**Кадры:** `frames/calib/calib_20261103-200433_1.jpg`, `calib2_201304.jpg`, вырезки `truck_zoom.jpg`
**Задача владельца:** «увидишь зад Toyota Tundra — найди его размеры и рассчитай по ним сработку детектора
для среднего человека».

---

## 1. Что измерено на кадре (субпиксельные границы, 50 % перепада)

| Объект | Пиксели (2 кадра — совпали) | Эталон | Масштаб |
|:--|--:|:--|--:|
| Задний номерной знак РФ | **27,3 px** по ширине | 0,520 м | **52,5 px/м** |
| Задний борт пикапа (между краями) | **92,0 px** | **1,70 м** (ширина самого борта) | **54,1 px/м** |
| **Принято** | | | **53,3 px/м** (расхождение 3 %) |

Важно: раньше я ошибочно сопоставлял борт с **габаритной шириной кузова 2,03 м** — это ширина по наружным
кромкам/зеркалам, а борт уже. С корректным эталоном (1,70 м) оба способа сходятся: 52,5 и 54,1 px/м.
Высота номера при этом масштабе — 6 px (наблюдаем 10 px из-за ИК-размытия), что подтверждает масштаб.

Справочные габариты Toyota Tundra (3-е поколение): **ширина 2,03 м**, высота 1,93 м, длина 5,81 м,
внутренняя ширина кузова ≈ 1,24 м, ширина борта ≈ 1,70 м.

## 2. Человек на этой дистанции

Средний рост **1,70 м** → **91 px** по высоте кадра = **8,4 %** высоты (1080 px).

| Рост | Пиксели в кадре | Доля кадра | В модели (640) | С дроблением 2×2 |
|:--|--:|--:|--:|--:|
| 1,60 м | 85 px | 7,9 % | 28 px | 57 px |
| **1,70 м** | **91 px** | **8,4 %** | **30 px** | **60 px** |
| 1,80 м | 96 px | 8,9 % | 32 px | 64 px |

## 3. Порог уверенной детекции

YOLOv5n устойчиво видит человека начиная с **20–25 px** по высоте в модели:

| Порог в модели | tiling=1 | tiling=2 | tiling=3 |
|:--|:--|:--|:--|
| 20 px | 1,13 м (×1,5 дистанции) | 0,56 м (**×3,0**) | 0,38 м (×4,5) |
| 25 px | 1,41 м (×1,2) | 0,71 м (**×2,4**) | 0,47 м (×3,6) |
| 30 px | 1,70 м (×1,0) | 0,85 м (**×2,0**) | 0,57 м (×3,0) |

Вывод: без дробления человек 1,70 м на дистанции пикапа — ровно на пороге 30 px; **дробление 2×2 даёт запас
вдвое** (60 px) и удваивает дальность уверенного распознавания.

## 4. Что выставлено в интеграции (проверено в живой системе)

| Параметр | Значение |
|:--|:--|
| `objects_tiling` | **2** — сначала весь кадр, если ничего не нашли — 2×2 фрагмента с перекрытием 12 % |
| `objects_conf` | **0.25** |
| `objects_min_h` | **0.02** (2 % ≈ 22 px) — человек 8,4 % проходит с запасом, мелкий шум отсекается |
| `objects_width` | **960** |
| `objects_require_motion` | вкл — припаркованная машина не держит свет |
| `objects_only_on_motion` | вкл — инференс только при движении |
| классы | `0,1,2,3,5,7` (человек, велосипед, машина, мотоцикл, автобус, грузовик) |

Задержка: 0,3–0,5 с при находке в полном кадре, 0,8–1,5 с при дроблении (только при движении).

## 5. Ограничения

1. Ночь/ИК: контраст ниже, дальше ×2,5 от пикапа возможны пропуски — тогда `objects_tiling=3` или модель крупнее.
2. Ствол дерева перекрывает часть борта — зону рисуем по открытой части двора.
3. Кадр ночной, погрешность масштаба ≈ ±3 % (два независимых эталона сошлись).
4. При повороте камеры/смене объектива калибровку пересчитать.

---

**Формулы:**

```
px_per_m    = ширина_объекта_px / ширина_объекта_м        (27.3 / 0.52 = 52.5;  92.0 / 1.70 = 54.1)
person_px   = рост_м × px_per_m                            (1.70 × 53.3 = 91 px)
доля_кадра  = person_px / высота_кадра                     (91 / 1080 = 0.084)
px_в_модели = person_px × (640 / ширина_кадра) × tiles     (91 × 640/1920 × 2 = 60 px)
дальность   ≈ текущая × (px_в_модели / минимальный_порог)  (60 / 25 = ×2.4)
```
