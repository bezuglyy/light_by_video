## 0. Резюме

Делаем **новую кастомную интеграцию Home Assistant** **`light_by_video` («Свет по видео»)** по образцу
`gate_vision` («Ворота»/«Обнаружение»): та же архитектура (координатор + зоны на кадре + панель + HTTP API +
сущности), но ядро другое — **обнаружение движения в нарисованной области кадра** с последующим
**включением выбранного устройства на заданное время** и автоматическим выключением.

Пилот (зафиксирован владельцем):
- **камера:** «Гостевой 13» — канал 13 на **Devline Line**-сервере `192.168.1.250`
  (`9786` веб-клиент, `9784` RTSP, `9780` основной), кадр `rtsp://…@192.168.1.250:9784/cameras/13/streaming/main`;
- **действие:** включить **`switch.svv_grozovaia_grozovaia_gostevoi_dom_switch`** («Грозовая гостевой дом Выключатель»,
  сейчас `off`, доступен) и выключить через N минут после последнего движения.

Новых зависимостей нет: `numpy` + `Pillow` уже в HA (на них работает `gate_vision`).
Ориентировочный срок: **4–6 рабочих дней** + 1 сутки живого тюнинга.

**Блокер P0 (нужно от владельца):** логин/пароль к Line-серверу `192.168.1.250` — известные нам учётки
(`admin/bezuglyy1983`, `admin/B@zuglyy`, `admin/P0$tCorp`, `admin/T@chlan2026`, `bezuglyy/B@zuglyy`, `admin/admin`)
получают **401** и на `:9786/cameras`, и на RTSP `:9784`. Без кредов не проверить, что канал 13 — именно «Гостевой».

## 3. Ключевые решения (ADR)

| # | Решение | Почему |
|:--|:--|:--|
| ADR-1 | Новая интеграция **`light_by_video`**, `gate_vision` не меняем | изоляция прода (ворота), независимые релизы |
| ADR-2 | Каркас копируем из `gate_vision`, ядро анализа — новое (`motion.py`) | проверено в проде на HA 2026.x, ноль новых зависимостей, панель знакома |
| ADR-3 | Детекция — разность кадров по области (grayscale, downscale, EMA-фон, маска) | единицы мс на зону, без GPU; работает в ИК |
| ADR-4 | Действие — «включить и держать N», а не «включить по фронту» | иначе свет гаснет, пока человек ещё внутри |
| ADR-5 | Панель с рисованием области — часть MVP | без неё интеграция бессмысленна |
| ADR-6 | Источник кадра — **URL/поток** (Line RTSP или go2rtc), `camera.*` — опция | камеры «Гостевой 13» в HA нет |
| ADR-7 | Действие — `homeassistant.turn_on/off` по `switch.*` | реле без яркости; работает и для `light.*` в других зонах |

### 4.2. Цикл (раз в `scan_interval`, по умолчанию 1,5 с)

```
кадр (go2rtc frame.jpeg | RTSP | HTTP-снапшот Line | camera.*)
  └─ PIL → L, downscale 480 px                                [executor]
      └ на зону: crop → blur → |cur − bg| > t → маска
          └ чистка (MinFilter/MaxFilter) → ratio изменённых пикселей
              └ подтверждение 2 из 3 → «движение»
                  └ actions.trigger(zone) → switch.turn_on + таймер N мин
                      └ продление по движению → выключение по тишине/лимиту
  └ bg = bg*(1−α) + cur*α  (α≈0.03; при глобальной смене света фон подтягивается быстрее)
```

## 6. Детектор движения (`motion.py`)

1. Кадр → `L`, downscale до 480 px (шум и стоимость падают).
2. `GaussianBlur(blur)` — давит шум ИК и артефакты JPEG.
3. На зону: `d = |cur − bg|`, `mask = d > t` (`diff_t` днём, `diff_t_ir` в ч/б ИК; цвет/ч-б — по насыщенности).
4. Чистка маски `MinFilter(3)` → `MaxFilter(3)`.
5. Метрики: `ratio = changed_px / zone_px`, `changed_px`, `mean_diff`, `bbox`.
6. **Глобальные изменения:** `ratio_global > global_change_ratio` → «смена света», состояние не меняется,
   фон подтягивается ускоренно; в журнал `lighting`.
7. Гистерезис: старт — `ratio ≥ min_ratio/sensitivity` и `changed_px ≥ min_px` в `confirm_frames` из `confirm_window`;
   конец — `quiet_frames` подряд ниже порога.
8. `mode: presence` — дополнительно «остаточное» отклонение от фона (стоящий человек), фон адаптируется медленнее.
9. `role: ignore` — маски помех (дорога, столб, качающаяся ветка, телевизор).
10. Нечитаемый кадр (`frame_mean < 15`) → `camera_lost`.

**Стоимость:** 8–15 мс на кадр при 480 px и 2–3 зонах → **<1 % ядра** на камеру при 1,5 с; замер — в P0
(кадр с Line может приходить большим — просить `width=640` у go2rtc или уменьшать после декодирования).

## 7. Действия: «включить на время» (`actions.py`)

```
IDLE ──движение──► ON (таймер hold_sec) ──новое движение + extend──► ON (таймер сброшен)
   ▲                   │
   │                   ├─ тишина hold_sec ─► OFF (если включали мы и restore позволяет) ─► IDLE
   │                   ├─ max_on_sec ──────► OFF (жёсткий лимит) ─► COOLDOWN
   └───────────────────┴─ выключение/сбой ─► OFF
```

1. **Проверки перед включением:** `enabled` (интеграция + зона), окно времени/дни, `lux_sensor < lux_below`,
   цель доступна (`not unavailable/unknown`).
2. **Включение:** `homeassistant.turn_on` (для `light.*` — с `brightness`, если задана); `scene`/`script` — вызов как есть.
3. **Запоминаем:** `was_on`, `on_since`, `last_motion`, `zone_id`.
4. **Выключение:** только если включали мы; `was_on == false` или `restore == true`; нет «карантина ручного
   вмешательства» (оператор сам переключил — не трогаем 10 мин).
5. **Продление:** новое движение при `extend=true` перезапускает `hold_sec`.
6. **Антидребезг/лимиты:** не чаще 1 команды в 5 с; не дольше `max_on_sec`; счётчики в журнале.
7. **Перезапуск HA:** активные таймеры и `was_on` → `Store` (`.storage/light_by_video.<entry_id>`);
   при старте — досчитать остаток либо выключить просроченное (свет не «зависает»).
8. **Журнал (200):** локальное время, зона, `ratio`, действие (`on/off/skip:lux/skip:time/skip:manual`), длительность.

| **Отладка** | метрики зон (ratio, px, bbox), версия, источник кадра, причина недоступности |

Грабли `gate_vision`, которые учтём сразу: уникальные `id` у кнопок (не `querySelector("button")`),
автосохранение зон с флагом `_dirty` (живое обновление не перетирает правки), локальное время в журнале,
cache-bust статики по `mtime`.

## 10. Деплой на «База»

| Шаг | Действие |
|:--|:--|
| 1 | Получить креды Line `192.168.1.250`, проверить кадр канала 13 (P0) |
| 2 | Завести поток в go2rtc: `gostevoy13: rtsp://<user>:<pass>@192.168.1.250:9784/cameras/13/streaming/main` (вариант A) |
| 3 | Бэкап `/config/lbv-backups/` + снимок HA (Supervisor backup) |
| 4 | Скопировать `custom_components/light_by_video/` на `192.168.103.200:/config/custom_components/` (SSH 2222) |
| 5 | `ha core restart` — **окно согласовать** (~1–2 мин без автоматизаций; сеть/ОПС/видео не затрагиваются) |
| 6 | Добавить интеграцию: Настройки → Устройства и службы → «Свет по видео» → источник = `gostevoy13` |
| 7 | Нарисовать зону, указать `switch.svv_grozovaia_grozovaia_gostevoi_dom_switch`, время, проверить «Проверить сейчас» |
| 8 | Включить действия на 1 зону, наблюдение сутки |

## 11. Тесты и приёмка

**Офлайн:** `tools/test_motion.py` на эталонных кадрах (человек в зоне / вне зоны / пусто / смена света / ИК-ночь);
замер мс/кадр.

**Живой прогон 1–2 суток на «Гостевом 13»:**

| Критерий | Норма |
|:--|:--|
| Задержка включения после входа в зону | ≤ 3 с (Line-кадр + подтверждение 2 кадра + Tuya) |
| Ложные срабатывания | ≤ 1/сутки на зону, причина видна в журнале |
| Пропуски (10 тестовых проходов) | ≤ 5 % |
| Продление | пока движение — не гаснет; после тишины гаснет за `hold_sec` ± 5 с |
| «Горело до нас» | не выключается |
| Перезапуск HA | таймер восстановлен, свет не «завис» |
| Нагрузка | ≤ 2 % CPU HA на камеру при 1,5 с |
| Лог HA | 0 новых WARNING/ERROR от `light_by_video` |

Пилот затрагивает **живой свет в гостевом доме** — включать действия только после отдельного «да» и в согласованное
время (не ночью), с готовностью выключить тумблером.

## 12. Риски и меры

| Риск | Вероятность | Мера |
|:--|:--|:--|
| Ложные срабатывания (фонари, листва, дождь, насекомые) | средняя | ignore-маски, min_ratio, confirm_frames, защита от глобального изменения, тюнинг по журналу |
| Слабая детекция в ИК (тёмная одежда) | средняя | `presence`, ночной множитель, позже — второй признак (PIR/событие Line) |
| Задержка/нестабильность Line-кадра | средняя | снапшот `:9786` как fallback, interval 2 с, проверка «камера недоступна» в журнале |
| Задержка Tuya-выключателя | средняя | замер в P0; при >3 с — рассмотреть локальный протокол/другой канал |
| Свет «залипает» | низкая | `max_on_sec`, persist таймеров, восстановление после рестарта |
| Рестарт HA в рабочее время | средняя | окно по согласованию, бэкап, только `ha core` |
| Свет в гостевом доме включается не вовремя | средняя | тумблеры, окно времени, `lux_below`, ручной «карантин» 10 мин |
| Обновление HA ломает кастом | средняя | версия+репозиторий, офлайн-тесты, эталонные кадры |
