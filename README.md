# «Свет по видео» (`light_by_video`) — интеграция Home Assistant

Включает выбранное устройство (свет, реле, прожектор) **на заданное время**, когда в **нарисованной на кадре
области** появляется движение. Автоматически выключает после тишины, продлевает при новом движении, не трогает
свет, который горел до срабатывания.

Сделана по образцу интеграции «Ворота» (`gate_vision`) — та же архитектура: координатор, зоны, панель, HTTP API.

## Возможности

- **Область на кадре** — рисуется мышью в панели, несколько зон, роли «движение»/«исключить», точные X/Y/Ш/В в %.
- **Детекция движения** — два режима:
  * **разность кадров** (EMA-фон, маска, сглаживание, день/ИК, защита от смены освещения);
  * **объекты** — YOLOv5n ONNX на CPU-сервисе (`detector/`, http://192.168.103.202:8099): в зоне засчитываются
    только человек/машина/мотоцикл/автобус/грузовик, причём **только вместе с движением** (иначе припаркованная
    машина держала бы свет). При недоступности сервиса — автоматический откат на разность кадров.
- **Действие на время** — включить и держать N минут, продление по движению, жёсткий лимит, антидребезг.
- **Условия** — датчик освещённости (`< lx`), окно времени, дни недели.
- **Бережное выключение** — не гасим то, что горело до нас (`restore`), не трогаем после ручного вмешательства.
- **Перезапуск HA** — активные таймеры восстанавливаются (Store), свет не «зависает».
- **Сущности** — движение по зоне, последнее движение, счётчик за сутки, метрика изменения кадра, тумблеры.
- **Журнал** — решения и причины пропусков, локальное время.

## Источники кадра

| Тип | Пример |
|:--|:--|
| Камера HA | `camera.gostevoy_13` (если заведена) |
| RTSP | `rtsp://user:pass@host:9784/cameras/12/streaming/sub` |
| go2rtc | имя потока (`garazh`) или `http://127.0.0.1:1984/api/frame.jpeg?src=…` |
| HTTP-снапшот | `http://host:9786/cameras/12/image?quality=80` (если поддерживается) |

Для RTSP используется PyAV (входит в Home Assistant), кадр берётся из фонового декодера.

## Установка

1. Скопировать папку `custom_components/light_by_video` в `/config/custom_components/`.
2. Перезапустить HA Core (`Настройки → Система → Перезапустить` или `ha core restart`).
3. **Настройки → Устройства и службы → Добавить интеграцию → «Свет по видео»** → указать поток и интервал.
4. Открыть панель **«Свет по видео»** в боковом меню: нарисовать область, выбрать устройство, задать время.

## Панель

- **Зоны** — рисование мышью, список, роль, чувствительность, точные координаты.
- **Действия** — устройство, «держать» и «максимум» в минутах, продление, «не гасить, если горело», lux, время, дни.
- **Детектор** — пороги, подтверждение/тишина, доля кадра для «смены света».
- **Журнал** — события и действия.
- Кнопки: «Проверить сейчас», «Показать маску», «Включить на 10 с».

## HTTP API (нужна авторизация HA)

```
GET  /api/light_by_video/state?entry_id=…
GET  /api/light_by_video/frame?entry_id=…
GET  /api/light_by_video/mask?entry_id=…        # PNG маски (отладка)
GET  /api/light_by_video/settings
POST /api/light_by_video/settings               # {"detector":{…}} {"zones":[…]} {"enabled":true}
POST /api/light_by_video/zone                   # {"action":"add|save|delete","id":…,"zone":{…}}
POST /api/light_by_video/test                   # {} | {"action":"on|off","zone_id":…}
GET  /api/light_by_video/events?limit=50
```

## События шины

`light_by_video_event` с полями `event` (`detected`, `cleared`, `action_on`, `action_off`, `skipped`,
`camera_lost`, `camera_back`, `lighting`), `zone`, `entity`, `reason`.

## Как это работает

1. Кадр (RTSP/HTTP/камера) → серый, уменьшение до 480 px, сглаживание.
2. Разность с фоном → маска → чистка → доля изменённых пикселей в каждой зоне.
3. Если доля ≥ порога (`min_ratio / чувствительность`) и пикселей ≥ `min_px` в `confirm_frames` кадрах — движение.
4. Действие: `turn_on` устройства + таймер `hold_sec`; при движении — продление; по тишине/лимиту — `turn_off`.
5. Фон подстраивается (`bg_alpha`); при глобальном изменении >55 % кадра кадр помечается «смена света» и в зонах
   ничего не меняется.

## Ограничения

- Детекция по разности кадров чувствительна к движущимся теням/листве — рисуйте зону только там, где нужен человек.
- Ночью в ИК чувствительность выше шумов: порог `diff_t_ir` ниже, проверяйте маску.
- На RTSP-источнике декодер держит поток постоянно (небольшая нагрузка на CPU).
- Пароль от потока хранится в настройках записи HA (`.storage`) — как у любой камеры.
